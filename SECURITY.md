No release is published yet. Once releases are cut from `main`, this section lists the supported versions.

| Version | Supported |
| --- | --- |

| _older versions_ | no |

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub Security Advisories — use Report a vulnerability on the repository's Security tab. Never open a public issue for a security problem.

You can expect a first response within 48 hours, followed by status updates until a fix ships.
